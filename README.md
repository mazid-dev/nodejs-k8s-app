# Node.js Kubernetes Deployment Project

## 📋 Project Overview
This project demonstrates deploying a Node.js application on Kubernetes using VMware infrastructure.

## 🏗️ Architecture
- Node.js (Express.js)
- Docker Container
- Kubernetes (kubeadm)
- VMware (3 VMs)
- Helm Charts
- Git Collaboration Workflow

## 👥 Team Structure
- **Developer**: Writes application code
- **DevOps Engineer**: Handles infrastructure and deployment

## 🌿 Branch Strategy
- `main` - Production-ready code
- `devops` - Infrastructure and deployment
- `developer` - Application development

1. Clone the repository
2. Checkout appropriate branch
3. Follow branch-specific instructions
